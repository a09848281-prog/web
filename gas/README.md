# GASセットアップ

1. 新しいGoogleスプレッドシートを作成します。
2. 「拡張機能」→「Apps Script」を開きます。
3. このフォルダの Code.gs をGASの Code.gs に貼り付けて保存します。
4. 関数一覧から setupDatabase を選択して実行し、権限を許可します。
5. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選択します。
6. 実行ユーザーは「自分」、アクセスできるユーザーは「全員」にします。実ユーザーと端末所有権はAPI内部で確認します。
7. /exec で終わるURLをコピーして web/config.json の gasUrl に設定します。

Webは非表示フォームとiframeのpostMessageブリッジを使用します。Androidは form POST の mode=json を使用します。映像・音声はGASを通りません。

注意：これは個人利用向けの実装ベースです。外部公開前に脅威モデリング、負荷試験、セキュリティレビューが必要です。スプレッドシートを公開しないでください。位置情報は機微情報として慎重に取り扱ってください。

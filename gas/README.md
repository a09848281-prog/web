# GASセットアップ v3.2

1. Googleスプレッドシートを作成します。
2. 「拡張機能」→「Apps Script」を開きます。
3. このフォルダーの Code.gs をGASの Code.gs に貼り付けて保存します。
4. 関数一覧から setupDatabase を選択して実行し、権限を許可します。
5. setupDatabase は既存行を消去せず、必要なシート・見出しを確認して `DB_SPREADSHEET_ID` をスクリプトプロパティへ保存します。v3.2へ更新した後は、旧版で実行済みでも必ず再実行してください。
6. 「デプロイ」→「デプロイを管理」→既存ウェブアプリの編集（鉛筆）→「新バージョン」→「デプロイ」で更新します。初回は「新しいデプロイ」→「ウェブアプリ」です。
7. 実行ユーザーは「自分」、アクセスできるユーザーは「全員」にします。
8. /exec URLを web/config.json の gasUrl に設定します。

## 接続確認
`/exec` をブラウザーで開くと `databaseReady` と `missingSheets` が表示されます。`databaseReady:true` が正常です。Web画面でも起動時に実際のPOST/iframe応答を確認します。GETで `ok:true` が表示されるだけではPOSTブリッジやDB接続の成功を意味しません。

## 認証方式
アカウント登録・ログインはありません。Androidの8桁ペアリングコード（10分有効）をWebに入力すると、そのAndroid端末専用の controllerToken が発行されます。コードは一度使用すると消費されます。紛失時はAndroidアプリの「ペアリングコードを再発行」を押し、Webで再ペアリングしてください。再ペアリング後は以前の操作トークンが無効になります。Web画面の「ペアリング解除」でもサーバー側のトークンを失効できます。

Webは非表示フォーム＋iframe postMessageブリッジを使用します。Androidは form POST の mode=json を使用します。映像・音声はGASを通りません。

注意：スプレッドシートは公開しないでください。controllerTokenはペアリングしたiPadのブラウザーローカルストレージに保存されます。共有端末では使用しないでください。位置情報は機微情報として慎重に取り扱ってください。

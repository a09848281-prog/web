# Remote Camera v4.5 Preview 仕様書

作成日：2026年11月19日  
状態：プレビュー開発版  
基準：v3.8 / v3.9 / v4.0 / v4.1 / v4.2 / v4.2.2  
構成：GitHub Pages Web + Android APK + GAS + Google Sheets + WebRTC  
AI：不使用  
Firebase：不使用

## 1. 目的
既存v4.2.2の機能・左設定／右映像の構成を維持し、映像上に利用者が指定した矩形範囲だけを対象にする、AIを使用しない動体検知を追加する。デザインは白を基調とするシンプルなUIへ変更する。

## 2. 画面構成
- 左側：端末ペアリング、映像・通信設定、位置情報、カメラ・マイク操作、動体検知設定、履歴、その他の操作。
- 右側：受信映像または地図を大きく表示。端末情報などの小さなステータス表示は維持。
- 動体検知範囲の追加操作は左側の「範囲を追加」から開始し、右側のライブ映像をドラッグして矩形を指定する。
- 最大8範囲。範囲ごとに有効／無効を切り替え、個別削除できる。
- 保存範囲は映像表示サイズではなく、映像フレームに対する0〜1の相対座標で保存する。解像度や表示サイズが変わっても位置を維持する。
- 白背景、淡いグレーの境界、薄い青のアクセントを使用。黒や濃色のパネル背景は使用しない。

## 3. 非AI動体検知
- 検知処理は閲覧側ブラウザー内で実行する。
- 受信映像から小さなサンプルフレームをCanvasに描画し、指定範囲内のRGB画素差分を比較する。
- 機械学習モデル、AI API、画像認識サービス、外部解析サーバーは使用しない。
- 検知感度：低／標準／高。
- 同じ範囲の通知は10秒間隔で抑制する。複数範囲で同時変化した場合は、サンプルごとに最も変化率の高い、通知抑制期間を過ぎた範囲を記録する。
- 動体検知は、Webページに映像が表示され、ページが前面にある間に動作する。ブラウザーがバックグラウンド化・休止した場合は検知が止まることがある。
- 映像の明るさ変化、画面揺れ、影、ノイズなどでも検知する場合がある。人物や物体を識別する機能ではない。

## 4. 通知・履歴・プライバシー
- 検知時はWeb画面内の通知、検知履歴、可能なブラウザー環境でのOS通知を表示する。
- 通知を利用者自身が許可する。iPadでOS通知を利用する場合は、対応OS・Safariの条件に従い、ホーム画面に追加したWebアプリとして開いて通知を許可する。
- 本プレビューにはサーバーからのWeb Push配信機構を実装しない。アプリを閉じた状態・ブラウザーが停止した状態でも通知が届くことは保証しない。
- 検知範囲とイベント履歴・静止画は閲覧ブラウザーのローカル保存領域に保存する。GAS、Sheets、Drive、Androidへ検知画像や範囲座標を送信しない。
- 履歴は最大12件。既存v4.2イベント履歴の読み込み互換を維持し、CSVへ範囲名を出力する。

## 5. GAS / Android
- GAS APIバージョンを4.5.0へ合わせる。
- Google Sheetsのテーブル構成は変更しない。新しい検知用シートや列を追加しない。
- Android側にAI・追加センサー・画像処理は追加しない。既存v4.2.2のカメラ・音声・通信機能を継承する。
- Android applicationId：`jp.a09848281.remotecamera.v45preview`
- Android versionCode：450
- Android versionName：4.5.0
- Web config appVersion：4.5.0
- GAS API version：4.5.0

## 6. プレビュー公開・互換性
- 開発ブランチ：`rebuild-v4.5-motion-zones-white-ui`
- 基準ブランチ：`rebuild-v4.2.2-ultra-stable-controls`
- Pages公開先：`/web/v4.5-preview/`
- 既存Webルート、v4.2.2プレビュー、旧ブランチ、PRは変更・統合しない。
- v4.5 APKは別applicationIdのため旧版と並行インストールできる。端末IDが新しくなるので、v4.5側で新しいペアリングを行う。
- GASはGitHub変更だけでは更新されない。既存Apps ScriptのCode.gsをv4.5ソースへ置き換え、新しいデプロイバージョンを公開する。

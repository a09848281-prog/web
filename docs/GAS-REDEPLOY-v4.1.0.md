# GAS v4.1.0 再デプロイ手順

v4.1 Web / AndroidはGAS API version `4.1.0` を確認します。GitHubのCode.gsを更新しても、公開中のApps Scriptデプロイは自動更新されません。

## 手順

1. 対象のGoogleスプレッドシートを開く。
2. **拡張機能 → Apps Script** から、現在このシステムに使っているApps Scriptを開く。
3. GitHubの [gas/Code.gs（v4.1ブランチ）](../gas/Code.gs) を開く。
4. Code.gsの内容をApps Script側へ反映し、保存する。
5. 既存のデータベーススプレッドシートIDと各シートのデータは維持する。今回のv4.1は新しいデータ列を追加していないため、既存データを削除・初期化しない。
6. Apps Scriptの **デプロイ → デプロイを管理** を開く。
7. 現在使用中のWebアプリデプロイの編集（鉛筆）を選ぶ。
8. バージョンを「新バージョン」にしてデプロイする。
9. 実行ユーザーは従来の設定を維持し、アクセスできるユーザーはWebアプリからの匿名リクエストを受け付けられる設定にする（既存設定を不用意に変更しない）。
10. 既存の `/exec` URLでGETを開き、応答JSONの `version` が `4.1.0` になっていることを確認する。

## 注意

- `setupDatabase()` は初回セットアップ時以外、むやみに実行しない。今回のv4.1ではスキーマ変更はない。
- デプロイURLが変わった場合だけ、`web/config.json` の `gasUrl` とAndroid設定の参照先を更新する。
- GAS APIが4.1.0でない状態では、WebのAPIバージョンチェックで不一致として表示される場合がある。
- API公開範囲・実行ユーザー設定は既存運用に合わせる。秘密情報や管理者キーをHTMLへ書かない。

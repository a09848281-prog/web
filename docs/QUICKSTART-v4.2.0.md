# Remote Camera v4.2.0 クイックスタート

## 1. GASを先に更新

1. v4.2ブランチの gas/Code.gs をApps Scriptへ貼り付ける。
2. 保存して setupDatabase() を実行する。既存シートを消去せず、Controllersシートを追加する。
3. Webアプリを新しいバージョンとして再デプロイする。既存のWebアプリURLを使い続ける場合も、デプロイの編集画面で新しいバージョンを選ぶ。
4. healthの応答が4.2.0で、databaseReady: trueになっていることを確認する。

## 2. Androidを登録

1. v4.2 APKをインストールする。v4.1とは別アプリとして共存できる。
2. アプリでカメラ・マイク・通知の権限を確認する。
3. 「Webからカメラ・マイクの起動を許可」をONにする。
4. 「監視待機を開始」を押し、Foreground Service通知を確認する。
5. Androidアプリに表示された8桁コードを使って最初のブラウザーを登録する。

## 3. iPad・PCをそれぞれ登録

1. iPadでv4.2 Webを開き、「Androidをペアリング」を押す。
2. Androidに表示された8桁コードを入力する。閲覧端末名には「iPad」などを設定する。
3. PCを追加する前にAndroid側の「コード再発行」を押す。
4. PCで同じv4.2 Webを開き、新しい8桁コードを入力し、名前に「PC」などを設定する。
5. 「登録済み閲覧端末を確認」で登録数と最終応答時刻を確認する。
6. Androidを選び、それぞれのブラウザーで「接続する」を押す。

最大3台。登録コードは一度使うと無効になるため、追加端末ごとにAndroidで再発行する。

## 4. 動体検知

- 「動体検知」をONにすると、そのブラウザー内で受信映像を解析する。
- 感度は低 / 標準 / 高から選択する。
- 必要に応じて「通知を許可」を押す。
- 「検知履歴」からサムネイルをタップすると、イベント画像を画面全体で表示できる。ビューアーの「保存」から画像を保存し、「閉じる」で元の画面に戻る。CSVも書き出せる。
- ライブ映像の「静止画保存」も、撮影した受信画像の全画面プレビューを表示する。
- ブックマークレット内で画像を開くと、パネル自体も画面いっぱいへ拡張する。画像ビューアーを閉じるとパネルの元の大きさへ戻る。
- 履歴と画像はそのブラウザー内だけに保存され、他の閲覧端末とは共有されない。画像データはGASへ送信されない。
- バックグラウンドや画面ロック中はブラウザーの省電力制御で解析が停止する場合がある。
- Safariのプライベートブラウズなどでローカル保存が使えない場合、閲覧端末情報や検知履歴を次回起動へ保存できないことがある。画像ビューアーの表示はできても、保存そのものはブラウザーの制限を受ける。

## 5. ブックマークレット

- docs/BOOKMARKLET-v4.2-UI.md の1行コードをSafari / ChromeのブックマークURL欄に登録する。
- ブックマークレットからv4.2の画面をフローティングUIで開ける。
- 埋め込みページでカメラ・マイク許可がブロックされた場合は「別タブ」を使う。

## 6. 注意

異なるWi-Fi / モバイル回線間の接続はTURN未構成のため保証されない。Androidが強制停止されている場合や、カメラ・マイク権限が取り消された場合は遠隔起動できない。実機テスト前のプレビューとして扱う。

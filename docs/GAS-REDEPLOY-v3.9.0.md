# GAS v3.9.0 再デプロイ手順

## 重要

Web v3.9.0 と Android v3.9 Preview は、GAS API v3.9.0 を必要とします。GitHub のコードを更新しただけでは、既存の Apps Script デプロイには反映されません。

## 手順

1. 既存の Google Apps Script プロジェクトを開きます。
2. GitHub の `gas/Code.gs` を開き、内容をすべてコピーします。
3. Apps Script の `Code.gs` を新しい内容で置き換えて保存します。
4. **デプロイ → デプロイを管理** を開き、既存のウェブアプリデプロイを編集します。
5. バージョンで **新バージョン** を選択し、デプロイします。
6. Web の設定画面を再読み込みし、GAS API バージョンが 3.9.0 と一致することを確認します。

## データについて

v3.9.0 は既存の Sheets テーブル構成を変更していません。画角と FPS は既存の `Settings.settingsJson` に保存します。既に DB を作成済みなら、通常は `setupDatabase()` を再実行する必要はありません。既存のスプレッドシートや行データを削除しないでください。

Web の `web/config.json` にある GAS URL は、現在使っているデプロイ URL を維持してください。別の Apps Script を新規作成した場合のみ、その URL に変更します。

## 確認

- Web 起動時に「GASバージョン不一致」と表示されない。
- API バージョンが `3.9.0` と表示される。
- ペアリング済み端末一覧が読み込める。
- 画質・画角・FPS・位置情報の設定を保存できる。

GASの6分実行制限は変更されません。接続中の命令は可能な限りWebRTCデータチャネルを利用します。

# Remote Camera v3.9.0 クイックスタート

## 1. 更新内容

- Webから 16:9 / 4:3 / 1:1 / 9:16 の画角を選択
- Webから 15 / 20 / 24 / 30 FPS を選択
- 360p / 480p / 720p / 1080p の画質選択
- 配信中のFPS・ビットレート調整
- 全画面終了後の映像再生復帰
- Androidマイクの受信音声ルートを明示
- Androidアプリ内で待機中の通信量モードを選択
- 静止画保存、画面スリープ防止、自動画質調整、Android電池情報、ライト操作

## 2. Android

1. v3.9 Preview APK をインストールします。v3.8 Preview とは別アプリとして共存します。
2. カメラ・マイク・通知の権限を許可します。
3. Androidアプリを開き、待機モードとバックグラウンド通信量モードを設定します。
4. 「監視待機を開始」を押します。
5. 表示された8桁コードをWebで登録します。

Androidアプリの設定画面を開いても、Foreground Service を停止しない設計です。待機サービスが動作している場合、画面を開くこと自体で配信を停止しません。

## 3. Web

1. Web画面を開いてAndroid端末を選択します。
2. カメラ接続を押します。
3. 映像・音声が届いたら「画角」「FPS」「画質」を選びます。
4. 画角・解像度変更は次回の接続から適用されます。FPS・送信ビットレートは接続中にも変更します。
5. 静止画保存、ライト、Android端末情報、画面スリープ防止を必要に応じて利用します。

## 4. テスト順

1. まず 16:9・720p・24 FPS で接続する。
2. Androidマイクの音声がWebに届くことを確認する。
3. 全画面にしてから戻し、映像が再生を続けるか確認する。
4. 切断後、4:3・1:1・9:16へ変更して再接続し、画角を確認する。
5. 15 / 20 / 30 FPS と自動画質調整を試す。
6. Androidアプリを開き直しても、接続が継続することを確認する。
7. ライトのON/OFF、静止画保存、電池表示を確認する。
8. 10分以上接続し、映像・音声が途切れないか確認する。

## 5. 制限と注意

- Camera2 が受け付ける撮影サイズ・FPSは機種依存です。要求どおりの値に非対応の場合は、対応する低い撮影形式へフォールバックします。
- 画角・解像度は配信中にCamera2を再起動しません。次回接続で反映します。
- Androidのトーチ（ライト）はカメラリソース使用中にOSから拒否される機種があります。Webに失敗が返る場合は、端末側制限の可能性があります。
- iPad Safari の画面スリープ防止はブラウザーの Wake Lock API 対応状況に依存します。
- STUNのみのため、接続ネットワークによってはTURN中継が必要です。
- Force Stop、端末再起動直後、権限取消、メーカー独自の強い省電力制御中の常時接続は保証できません。
- 実機テスト完了前のプレビュー版です。旧版はテスト終了まで削除しないでください。

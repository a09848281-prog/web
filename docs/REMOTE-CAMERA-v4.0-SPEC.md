# Remote Camera v4.0 Preview

## 基本方針
- v3.9の機能・画面構成・デザインを維持して継承する。
- v3.9ブランチを基点にした独立ブランチで開発する。
- mainおよびv3.9のコードは変更しない。
- Firebaseは導入しない。既存のGitHub Pages + GAS + Sheets + WebRTC構成を維持する。

## v3.9から引き継ぐ主な機能
- Androidカメラの広角優先選択、画角、FPS、画質・通信量設定
- 全画面表示と復帰時の映像再生復旧
- ライト、端末状態、静止画保存、位置情報
- バックグラウンド待機、待機通信モード、画面OFF中のCPU維持設定
- WebRTC再接続、映像フリーズ監視、GAS通信リトライ

## v4.0 音声新機能7項目
1. **環境音優先マイク**：Androidの音声ソースをMICにし、通話向けの音声処理を避ける。
2. **受信音量ブースト**：Web側で0〜200%に調整。100%超は音割れの可能性がある。
3. **マイク音量メーター**：受信音声のRMSレベルをWeb画面に表示。
4. **左側の大型プッシュトーク**：映像画面の操作列先頭に配置し、既存デザインを維持。
5. **送話ロック**：ボタンを押し続けずに送話状態を維持・解除できる。
6. **Android音声ミュート**：WebからAndroid側の受信音声を一時ミュートできる。
7. **音声状態表示**：マイク音量メーターとトラック状態で、音が届いているかを確認しやすくする。

## 音声の注意
- 環境音優先設定は、静かな音を拾いやすくする一方、スピーカー音の回り込み・エコー・環境ノイズも増える場合がある。
- Android端末の機種・マイク位置・権限・音量制御・WebRTCライブラリの処理により結果は異なる。
- Web受信音量200%はAndroidマイク自体の入力感度を上げるものではなく、iPad/PC側で受け取った音を増幅する。
- Galaxy A22 5G / Android 13 と iPad Safariで、実機確認が必要。CI成功だけで音質や実機動作を保証しない。

## テスト項目
- Androidを待機状態にしてWebから接続、環境音を静かな音／通常会話／大きな音で確認
- PTTを短押し・長押し・ロックON/OFF・画面回転で確認
- PTT中はAndroidからの戻り音声が抑制され、解除後に戻ること
- WebのAndroid音声ミュート切替が機能すること
- 受信音量0/70/100/150/200%で音割れと音量を確認
- 全画面の出入り後も映像・音声・操作が継続すること
- Androidアプリ画面を開いても待機サービス・既存接続が停止しないこと
- 省電力・標準・高画質モードで通信と発熱・電池消費を比較

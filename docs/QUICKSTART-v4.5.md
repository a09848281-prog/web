# Remote Camera v4.5 Preview — クイックスタート

## 1. GAS
先に `docs/GAS-REDEPLOY-v4.5.md` の手順でGAS APIを4.5.0へ更新します。旧版のAPIのままだと、バージョン不一致でペアリング操作が無効になります。

## 2. Android APK
GitHub Actionsの「Validate Remote Camera v4.5 Preview」が成功した実行を開き、Artifactsから `remote-camera-debug-apk-v4.5-preview` をダウンロードします。ZIPを展開して `app-debug.apk` をインストールし、カメラ・マイク・通知など必要な権限を許可します。
v4.5は旧版とは別アプリとしてインストールできます。Androidで新しい8桁コードを発行し、Web側で登録してください。

## 3. Web
次のプレビューを開きます。

https://a09848281-prog.github.io/web/v4.5-preview/

左側でAndroidをペアリングして接続します。右側にライブ映像が表示されたら、左側の「指定範囲の動体検知」で「範囲を追加」を押します。右側の映像上を指またはマウスでドラッグし、監視したい四角い範囲を指定します。必要に応じて最大8範囲まで追加できます。

範囲を作成した後、「動体検知を有効にする」をONにします。検知感度を選び、「iPadの通知を許可」から通知許可を設定します。検知範囲・履歴はこのブラウザーに保存されます。

## 4. iPadの通知について
iPadOSの対応バージョンで、Webサイトをホーム画面に追加してWebアプリとして開き、通知を許可してください。通知機能が使えない環境でも、Web画面内の警告と検知履歴は利用できます。
このプレビューでは、Webページが閉じている間やブラウザーが停止している間に通知を送るサーバー側Web Pushは実装していません。動体検知自体も映像を受信している前面表示中に動作します。

## 5. 旧版の保護
v4.5は専用ブランチ・専用Pagesパス・専用Android applicationIdで公開します。v4.2.2やmainのファイルを置き換えず、PRも自動マージしません。

# Remote Camera v3.5 再構築仕様

更新日：2026-11-18
対象リポジトリ：a09848281-prog/web
作業ブランチ：rebuild-v3.5-remote-standby
対象実機：Galaxy A22 5G / Android 13
用途：所有者が設置・管理する個人用ネットワークカメラ

## 1. v3.5で行う修正

### 1.1 WebRTCクラッシュ対策

確認されたログ：

- `SecurityException`
- `android.permission.ACCESS_NETWORK_STATE` が許可されていない
- `NetworkMonitorAutoDetect` が `ConnectivityManager.getActiveNetworkInfo()` を呼び出す
- 直後に `jvm.cc` の `Check failed: false` と `SIGABRT`

AndroidManifest.xml に `ACCESS_NETWORK_STATE` を明示し、WebRTC初期化直前にも権限の有無を検査する。権限がなければネイティブWebRTC処理へ進まず、Logcatと通知に原因を表示する。

v3.3.0のビルド記録に記載されたcommit（c4ef8fe）時点のManifestにはこの権限がなかった。現行mainには追加済みだったため、今回のログは権限追加前のAPKで発生した可能性が高い。v3.5.0はversionCode 305へ上げ、成果物にも権限が含まれていることをCIで検査する。

### 1.2 Android側のバックグラウンド設定

| モード | GAS確認間隔 | 用途 |
|---|---:|---|
| 省電力 | 60秒 | 待機時間が長いとき |
| 標準 | 15秒 | 通常利用 |
| 応答優先 | 5秒 | 接続開始の応答を優先 |

確認間隔はAndroidアプリ内で変更し、設定を端末に保存する。待機中に変更した場合は起動中サービスにも反映する。

### 1.3 遠隔メディア許可

Androidアプリに「Webからカメラ・マイクの起動を許可」スイッチを設ける。

- ON：端末の所有者がAndroidアプリから監視待機を開始している間、Webからの接続要求を処理する。
- OFF：既存RTCセッションを終了し、新しい接続要求を拒否する。
- 待機中：カメラ・マイクは取得せず、接続要求のみを待つ。
- 接続中：Androidのプライバシー表示と常時通知にカメラ・マイク使用中の状態を表示する。

### 1.4 サービスの復旧

Androidシステムがメモリ回収などでサービスを終了した場合に備え、保存済み設定と権限を再確認したうえで、システムによるサービス再生成時の復旧を試みる。これはベストエフォートであり、強制停止・端末再起動・権限取消・メーカー独自の省電力終了からの自動復帰を保証しない。

## 3. Android OSの制約

本アプリは、Androidアプリを所有者が画面表示中に開き、必要なカメラ・マイク・通知権限を許可し、「監視待機を開始」を押した状態を前提とする。カメラ・マイクを使うForeground Serviceと継続通知を利用する。

Android 12以降はバックグラウンドからForeground Serviceを自由に新規起動できない。カメラ・マイクは「使用中のみ」の権限制約も受ける。このため、Webからの命令だけで、未起動・強制停止中・再起動直後のアプリを秘密裏に起動して撮影する設計にはしない。

画面ロック後の接続は、事前にユーザーが開始したForeground Serviceが維持され、権限・プライバシー設定・通信が利用可能な場合に限り試行する。撮影・録音中はAndroidのシステム表示と通知を維持する。

## 4. 受け入れ試験

1. ビルド後APKのManifestに `INTERNET`、`ACCESS_NETWORK_STATE`、`CAMERA`、`RECORD_AUDIO` が実際に含まれる。
2. Galaxy A22 5G / Android 13で監視待機を開始できる。
3. 待機中はカメラ・マイクを取得せず、通知に待機中と表示する。
4. Webから接続すると、Android通知とプライバシー表示が撮影・録音中へ変わる。
5. 画面ロック後の接続継続を実機で確認する。
6. Android側で遠隔起動許可をOFFにすると、既存セッションが停止し、新規要求が拒否される。
7. 省電力・標準・応答優先でポーリング間隔が変わる。
8. WebRTC接続失敗時もAndroidサービスが異常終了せず、Logcatに原因を残す。
9. 通知の停止操作で待機・RTC・カメラ・マイクが終了する。
10. GitHub ActionsのAndroidビルドとWeb/GAS構文・API整合性検査が成功する。

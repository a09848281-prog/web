# Remote Camera v4.1.0 クイックスタート

この手順はAndroid APKとiPad/PC Webビューアーを使う個人利用向けです。v4.1プレビューはv3.9 / v4.0と並行インストールできる別アプリIDです。

## 1. APKを入手

1. GitHubリポジトリの **Actions** を開く。
2. `Build Android APK` のv4.1ブランチ／PRの最新実行を選ぶ。
3. 実行が成功（緑のチェック）していることを確認する。
4. Artifactsから `remote-camera-debug-apk-v4.1` をダウンロードする。
5. ZIPを展開し、中の `app-debug.apk` をAndroidへ移す。
6. AndroidでAPKを開き、ブラウザー／ファイルアプリに「この提供元からのアプリを許可」を一時的に許可してインストールする。

## 2. Androidの初期設定

1. Remote Camera 4.1 Previewを開く。
2. カメラとマイクの権限を許可する。通知権限も許可する。
3. 位置情報を使う場合だけ位置情報を許可する（位置情報は必須ではない）。
4. 「Androidマイクの集音モード」は、周囲の音を優先する場合は **環境音重視** にする。
5. 「Webからカメラ・マイクの起動を許可」をONにする。
6. 待機間隔と通信量モードを選ぶ。
7. 「監視待機を開始」を押す。
8. 通知欄に待機中のForeground Service通知が出ていることを確認する。

待機中は録画・録音していません。Webから接続要求を受けてからカメラ・マイクを起動します。設定画面を開き直してもサービスを停止しない設計です。

## 3. Webからペアリング

1. v4.1のWebソースを配信しているプレビュー環境を開く。
2. 「Androidを追加」を押す。
3. Androidに表示された8桁コードを入力する。
4. ペアリング済み端末を選び、「接続する」を押す。
5. Android側の通知とプライバシー表示でカメラ・マイクの使用状態を確認する。

**注意：** GitHub Pagesの正式URLはmain側のソースを表示します。v4.1のWebソースがプレビューへ公開されるまでは、正式URLだけではv4.1のWeb UIに切り替わりません。v4.1のWebをmainへ反映する前に、別のプレビュー配信手段または統合作業が必要です。

## 4. マイク・音声の調整

- Androidで「環境音重視」を選択すると、通話向けエコーキャンセル／ノイズ抑制を避けて周囲の音を優先します。
- 「バランス」は雑音低減を加え、「声重視」は通話向け処理を使います。
- 接続中にAndroidモードを変更しても現在の接続を切断せず、次のWeb接続から反映します。
- Webの受信音量は初期70%、最大200%。100%を超えると音割れする場合があります。
- マイク音量メーターはWebが受信した音声レベルを示します。
- 「Androidスピーカー音量」はiPadから送ったPTT音声をAndroidで再生するときの音量です。iPad側の受信音量とは別に調整します。
- PTTは押している間だけ送話。送話ロックは連続送話に使用し、3分で自動解除されます。

## 5. 接続できない場合

- Androidの待機サービス通知が残っているか確認する。
- カメラ／マイク権限と「Webから起動許可」を確認する。
- Androidが強制停止されていないか、メーカー独自の省電力設定がサービスを停止していないか確認する。
- WebとGASのバージョンが4.1.0で一致しているか確認する。
- 異なるネットワーク間ではTURN未構成のため接続できない場合がある。両端末を同じWi-Fiに接続して切り分ける。
- Androidで別のカメラ・通話・録音アプリがカメラ／マイクを使用していないか確認する。

## 6. Android側の制約

アプリ強制停止、端末再起動直後、権限取消、ネットワーク切断、OSのバックグラウンド制限を超えて、常に遠隔でカメラを起動することはAndroid上保証できません。待機を開始した状態でForeground Service通知を維持してください。

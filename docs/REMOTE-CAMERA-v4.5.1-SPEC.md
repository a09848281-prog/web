# Remote Camera v4.5.1 Preview — 範囲指定・人物候補検知

作成日：2026年11月19日  
状態：開発プレビュー／実機検証前  
基準：v4.2.2（v3.8・v3.9・v4.0・v4.1・v4.2の記録済み機能を継承）  
v4.3：リポジトリ内に既存ブランチ・仕様書・ビルド記録を確認できなかったため、未確認仕様は推測で追加しない。

## 目的
- ライブ映像上をドラッグして監視範囲を設定。
- 指定範囲内だけでフレーム差分による動体検知。
- 人物らしい縦長の動き候補、範囲への進入・退出、領域数の概算、移動方向を記録。
- 白基調。左に設定・操作、右に映像・地図。

## 動体検知
- 初期値は全画面範囲1つ。最初の手動範囲を描画すると全画面範囲を置換する。最大8範囲、範囲ごとに名前・有効/停止・感度を保存。表示ズーム倍率・全画面切替後もドラッグ座標を補正する。
- 座標は映像に対する0〜1の正規化値。端末画面寸法の変更にも対応。
- 受信映像を160×90へ縮小して画素差分を比較。大きな全画面変化は照明変化等として抑制。
- 時刻、範囲名、変化率、イベント種別、縮小JPEGをブラウザー内に最大20件保存。CSV出力。
- 映像・範囲・イベント画像はGAS/Sheetsへ送信しない。

## 人物候補
- 差分領域の連結成分、面積、縦横比などから人物らしい動きの候補を推定。縦横比は元映像の縦横比に合わせて補正し、縦長映像にも対応。
- 範囲進入・退出をイベント化。動く縦長領域の数を候補数として概算し、位置差から方向を推定。
- 本人確認・顔認識・属性推定・個人追跡は行わない。荷物・影・扉などの誤判定があり、実人数の保証はない。
- 外部AI API、外部人物検出API、Firebase、新規SDK/JSライブラリは追加しない。既存v4.2.2の地図だけはLeaflet (unpkg) と OpenStreetMapタイルを引き続き利用し、検知処理からは利用しない。

## PWA・通知
- Web App Manifestと同一オリジンのService Workerを追加。アプリシェルをキャッシュ。
- 通知はPWAのページ処理が動作中に、利用者が許可した場合にローカル通知を表示。
- iPadOS/SafariがバックグラウンドでPWAを休止した場合、映像解析は継続できない。外部Pushサービスを使わない条件では休止中の即時通知を保証できないため実装対象外。復帰後はローカル履歴を確認する。
- Service WorkerはPushイベントを使用しない。

## 画面
- PCでは左設定／右画面の2列。モバイルでは既存の縦積みレスポンシブを維持。
- 白背景と薄い青・灰色のアクセント。黒いパネル・黒背景を使わない。

## 互換性
- Android撮影・WebRTC処理は変更しない。新APKのリモート設定取得先のみv4.5.1ブランチの `web/config.json` へ切り替え、プレビュー用GAS URLと一致させる。Android APKのapplicationIdは `jp.a09848281.remotecamera.v451preview`、versionCode 451、versionName 4.5.1。
- GASはバージョン表記のみ4.5.1へ更新。シート名・列・既存データ・認証方式は維持。
- WebのペアリングLocalStorageキーはv4.2を維持。旧検知履歴キーを読み込み、新キーへ保存。
- 旧APKと並行インストール可能。新APKでは新しいペアリングが必要。

## 制約
- CI成功とGalaxy A22 5G / Android 13・iPad Safari実機確認は別。
- STUNのみでTURN中継は未構成。異なるネットワーク接続は保証しない。

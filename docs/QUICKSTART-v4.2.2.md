# Remote Camera v4.2.2 — クイックスタート

## APK
GitHub Actionsで `Validate Remote Camera v4.2.2` が成功した実行を開き、Artifactsの `remote-camera-debug-apk-v4.2.2` をダウンロードする。ZIPを展開して `app-debug.apk` をAndroidへインストールし、カメラ・マイク・通知・必要に応じて位置情報の権限を許可する。v4.2.2は旧v4.2 Previewとは別アプリとして入るため、旧版をアンインストールする必要はない。新しいアプリを起動し、新しく表示されたペアリングコードをWebに入力する。

## GAS
`docs/GAS-REDEPLOY-v4.2.2.md` に従い、`gas/Code.gs` を既存Apps Scriptへ貼り替えて新バージョンをデプロイする。既存スプレッドシートのデータは削除しない。

## Web
Webページを開き、左側でAndroidをペアリングして接続する。右側には受信映像または地図を大きく表示する。設定は左側に集約。画質・画角・FPSを変更すると、ペアリング中は保存とAndroidへの反映を試みる。

## 主な機能
- **ライト**：左側のライトボタン。Androidから完了応答が戻るまで「切替中」と表示する。
- **音声フィルター**：左側スライダー。0%は未処理、100%は強めのWeb Audio EQ/コンプレッサー/ソフトゲート。
- **全画面**：左側の全画面ボタン。右側の映像だけを拡大。
- **位置情報**：直近のキャッシュがあれば先に表示し、後から新しい測位で更新する。
- **端末情報**：右上にAndroid監視時間・アプリ通信量の概算を小さく表示。
- **閲覧側通信量**：右上に現在のWebRTCセッション通信量の概算を表示。

60fps・位置情報の速度・音声フィルターの効果は端末・OS・ブラウザ・回線条件に依存する。音声フィルターはAI音声分離ではない。TURNサーバー未設定のため、異なるネットワーク間の接続が失敗する場合がある。

# Remote Camera v4.2.0 — 複数端末同時監視仕様書

作成日：2026年11月19日  
状態：実機検証前の開発プレビュー  
対象：Android 13端末 / iPad / PC  
方式：Android APK + WebRTC + GitHub Pages配信Web + GAS + Google Sheets  
Firebase：不使用

## 1. v4.2の目的

Android端末を一度登録した後、iPad・PCなど最大3台の閲覧端末から同じカメラ映像と音声を同時に受信できるようにする。既存v4.1の単一コントローラー認証を、閲覧端末ごとの独立したトークンに変更する。

## 2. v4.2で追加する6機能

1. **最大3台の同時監視** — Android 1台に最大3つのWebRTCセッションを作成。4台目の接続は明確なエラーを返す。
2. **閲覧端末ごとの独立登録・切断** — Androidでコードを再発行し、各ブラウザーを個別登録。1台の切断・登録解除で他の端末の映像を止めない。
3. **閲覧端末一覧** — 登録名、オンライン確認状況、最終応答時刻、現在のブラウザーを表示。
4. **ブラウザー内の動体検知** — オプトイン方式。低・標準・高の3段階。映像フレームの変化を各閲覧ブラウザー内で解析する。
5. **検知スナップショット・履歴・通知** — 最大12件のイベントと小さなJPEG静止画をブラウザーのローカル保存領域に保持。CSV出力と、利用者が許可した場合のブラウザー通知に対応。
6. **受信画像ビューアー** — ライブ受信映像から静止画を作成すると画面全体のビューアーを開く。動体検知履歴のサムネイルもタップで全画面表示でき、ビューアーから保存・閉じる操作を行える。ブックマークレット内では親パネルも全画面へ拡張し、閉じると元の大きさへ戻す。画像はGAS / Sheetsへ送信せず、表示を閉じた時点で一時画像URLを解放する。

## 3. 接続モデル

- Androidは一度だけ初期登録し、Foreground Serviceで監視待機する。
- 追加するiPad / PCごとにAndroid側で8桁コードを再発行し、その端末のブラウザーでペアリングする。
- 登録情報はブラウザーごとに独立して保存される。v4.2はv4.1と分離したLocalStorageキーを使うため、初回のみ再ペアリングが必要。
- GASのControllersシートに閲覧端末ごとのハッシュ化トークンを保存する。生トークンはブラウザー側のローカル領域に保存する。
- AndroidはセッションごとのPeerConnectionを管理し、最大3接続まで共有カメラ・マイクトラックを配信する。
- 各閲覧端末の「切断」はその端末のsessionIdだけを閉じる。他の視聴端末やAndroid待機サービス全体を終了しない。

## 4. 継承機能

- 画角：16:9 / 4:3 / 1:1 / 9:16
- FPS：15 / 20 / 24 / 30、画質：360p / 480p / 720p / 1080p
- 通信量モード、自動画質調整、カメラ切替、ライト、ズーム、全体表示、全画面復帰、受信静止画の全画面ビューアーとJPEG保存
- Android端末情報、電池情報、位置情報・地図・履歴・削除
- Foreground Service待機、待機モード、通信量設定、CPU維持設定
- Androidマイクの環境音重視 / バランス / 声重視
- Web受信音量、ミュート、PTT、送話ロックと安全タイムアウト、Androidスピーカー音量
- WebRTC再接続、フレーム監視、GASリトライ、接続統計
- 登録・ログインなし、8桁コードによる登録、Firebase不使用

## 5. 安全・プライバシー

- Android通知とOSのカメラ・マイク使用表示を維持する。待機中に無断で撮影・録音を行わない。
- 動体検知はWeb側で明示的にONにした場合だけ動作する。Androidに新たな録画機能を追加しない。
- 動体検知データと静止画は閲覧端末のブラウザー内だけに保存し、GAS / Sheets / Driveへ送信しない。受信画像ビューアーもブラウザー内だけで動作し、画像表示を閉じると一時URLを解放する。
- LocalStorageへのアクセスが拒否・容量不足となった場合は、画面全体を停止させず、ペアリング情報・設定・イベント履歴を保存できない可能性を通知する。イベント画像の保存に失敗した場合は画像なしのイベント情報で保存を再試行する。
- WebRTCのICE候補収集が25秒以内に完了しない場合、不完全なSDPをAndroidへ送らず、接続を失敗として再試行する。手動切断・自動再接続時はDataChannelとsessionId付きGAS byeの両方で終了を通知する。
- ブラウザーがバックグラウンド停止・休止した場合、動体検知や通知も停止する可能性がある。
- 閲覧端末は最大3台。共有カメラの画質・カメラ方向・ライトなどの端末共通設定は、最後に操作した閲覧端末の変更が全員に反映される。
- PTT音声は各WebRTCセッションから送信される。複数端末の同時送話は音声が重なる場合がある。
- 接続にはSTUNを使用。TURNリレーは未構成なので、異なるネットワークや制限の強い回線では接続できないことがある。
- Androidの強制停止、再起動直後、権限取消、OSによるバックグラウンド制限からの遠隔起動は保証しない。
- v4.2のGASへ更新する際は setupDatabase() を実行してControllersシートを追加する。既存データを消去しない実装。
- v4.1以前の既存閲覧トークンは初回アクセス時に新しいControllersシートへ移行する。別のブラウザーを追加するにはAndroidでコードを再発行する。
- Pagesプレビューは専用のActions環境 `github-pages-v42-preview` へデプロイする。元の `main` 側公開ワークフローと専用のデプロイ環境を分け、デプロイは同じ `github-pages` concurrency groupで直列化する。復帰時はmain用の既存ワークフローを実行する。

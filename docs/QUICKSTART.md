# セットアップ手順 v3.1（ログイン不要）

## 1. GASとスプレッドシート
1. Google Sheetを作成します。
2. 「拡張機能」→「Apps Script」を開きます。
3. gas/Code.gs の最新版を Code.gs に貼り付けて保存します。
4. 関数一覧から setupDatabase を選び、実行して権限を許可します。
5. 既存シートがある場合も、setupDatabase は既存データを消さず必要な末尾列を追加します。
6. 初回は「新しいデプロイ」→「ウェブアプリ」。既存環境は「デプロイを管理」から新バージョンへ更新します。
7. 実行ユーザーは「自分」、アクセスできるユーザーは「全員」にします。
8. /exec URLが現在の web/config.json に設定されていることを確認します。

## 2. GitHub Pages
1. GitHubリポジトリの Settings → Pages を開きます。
2. Build and deployment の Source を GitHub Actions にします。
3. Actions → Deploy Web Pages を実行します。
4. 公開URL： https://a09848281-prog.github.io/web/

## 3. Androidの準備
1. 最新の debug APK を GitHub Actions の Build Android APK から取得してインストールします。
2. Android 13端末でアプリを開きます。
3. カメラ・マイク・位置情報・通知の権限を許可します。
4. 「監視待機を開始」を押します。
5. Android画面に8桁のペアリングコードが表示されます。

## 4. iPadからペアリング
1. iPad SafariでGitHub Pagesを開きます。
2. 「Androidをペアリング」を押します。
3. Androidに表示された8桁コードを入力します。
4. ペアリングが成功すると端末が一覧に表示され、監視操作画面を使えるようになります。

ユーザー登録・ログインはありません。操作トークンはこのiPadのブラウザーローカルストレージに保存されます。ブラウザーのサイトデータを削除した場合は、Androidアプリで「ペアリングコードを再発行」して再ペアリングしてください。

## 5. 接続テスト
1. ペアリング済み端末を選択します。
2. 「接続」を押し、iPad Safariのマイク権限を許可します。
3. 映像・音声、プッシュトゥトーク、カメラ切り替え、音量、位置情報を確認します。

## 注意
Androidは約30秒ごとにGASを確認します。STUN/TURNを使用しないため、まず同じWi-Fi/LAN内で接続してください。異なるネットワーク間では接続しない場合があります。Androidの強制停止・再起動・権限取消・メーカー省電力制御後の自動復帰は保証されません。

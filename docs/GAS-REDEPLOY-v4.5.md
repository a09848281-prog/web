# Remote Camera v4.5 Preview — GAS更新手順

1. Google Apps Scriptで、現在Remote Camera v4.2.2に使っているプロジェクトを開きます。
2. GitHubの `gas/Code.gs`（v4.5ブランチ）を開き、内容をコピーします。
3. Apps Scriptの既存 `Code.gs` を置き換えて保存します。
4. 既存スプレッドシートのデータは削除しません。v4.5ではテーブル構成を変更していません。すでにv4.2.2でDB設定済みなら、通常は `setupDatabase()` の再実行は不要です。ヘルスチェックでDB未設定・テーブル不足と表示された場合のみ、対象スプレッドシートに紐づくApps Scriptで `setupDatabase()` を実行してください。
5. 「デプロイ」→「デプロイを管理」から既存ウェブアプリを編集し、新しいバージョンを選択してデプロイします。既存の `/exec` URLを維持することを推奨します。
6. Web側の `web/config.json` の `gasUrl` が同じ `/exec` URLを指していることを確認します。
7. v4.5プレビューを開き、Webの初期状態に「GAS接続済み」と表示されることを確認します。Web APIとGAS APIのバージョンは両方4.5.0で一致する必要があります。

注意：
- GitHubへコミットしてもApps Scriptの公開デプロイは自動更新されません。
- 既存デプロイを残したい場合は「新しいデプロイ」を作成し、そのURLをWebの `gasUrl` に設定してください。
- スプレッドシートの既存データを手動で消去しないでください。
- このバージョンの動体検知範囲・イベント画像はブラウザー内だけに保存し、GASへ送信しません。

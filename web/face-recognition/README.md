# Face ID Studio

GitHub Pagesで動く端末内処理型の顔認識Webアプリです。既存の遠隔監視カメラWebアプリとは分離し、web/face-recognition/ 配下に追加しています。

## 起動
1. GitHub Pagesでリポジトリを公開します。
2. https://a09848281-prog.github.io/web/face-recognition/ をHTTPSで開きます。
3. カメラを許可します。
4. 登録人物から同じ人物の顔サンプルを3枚以上登録します。
5. リアルタイム認識でカメラを起動します。

## 実装内容
- 複数人物の登録・削除、複数サンプル保存
- face-api.jsによる顔検出・68点ランドマーク・顔特徴量照合
- 複数顔の同時検出、右側の人物一覧、未登録者表示
- 一致度の目安表示、しきい値調整
- 顔向きの簡易推定、まばたきの簡易検出
- 最新10件の認証イベント履歴
- ローカル人物ロール（表示・分類用）
- IndexedDB保存、全データ削除、PWAシェルキャッシュ

## 通信とプライバシー
顔画像・特徴量・履歴はIndexedDBに保存し、アプリから外部サーバーへ送信しません。認識ライブラリとモデル重みはjsDelivr CDNから静的ファイルとして読み込みます。初回起動時はインターネット接続が必要です。CDNへのモデル取得通信は発生しますが、カメラ映像や顔データは送信しません。

## 重要な制約
- 一致度の数値は本人である確率ではありません。照明・角度・カメラ・登録品質で変化します。
- まばたき検出は簡易判定であり、写真・動画・画面表示を確実に見破る生体検知ではありません。
- 顔向き推定もランドマークによる簡易推定です。
- 人物ロールは端末内のUI分類であり、認証・アクセス制御・改ざん防止ではありません。
- カメラはHTTPSと利用者の許可が必要です。タブを閉じる・バックグラウンド化すると停止する場合があります。
- PWAの画面ファイルはキャッシュしますが、外部CDNのライブラリ・モデルが初回取得できない場合は認識機能を利用できません。
- 本人の同意を得て利用し、重要な本人確認や入退室管理の唯一の手段として使用しないでください。
